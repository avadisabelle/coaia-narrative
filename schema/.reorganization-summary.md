# Schema Folder Reorganization - Summary

**Date:** 2026-02-13  
**Version:** 2.3.0

## What Changed

### Before
- Flat structure with 52 individual schema files
- No clear organization or categorization
- Missing central data model documentation
- No discovery mechanism for external apps

### After
- Hierarchical organization by category
- Comprehensive README documentation at each level
- Central registry (index.json/yaml)
- Consolidated data model file (data-model-complete.json/yaml)
- Example payloads for common use cases

## New Structure

```
schema/
├── README.md                        ✨ Main navigation guide
├── index.json|yaml                  ✨ Central registry
├── data-model-complete.json|yaml    ✨ All data schemas in one file
│
├── data-model/                      ✨ Core data structures
│   ├── README.md
│   ├── entity.json|yaml
│   ├── relation.json|yaml
│   ├── knowledge-graph.json|yaml
│   └── storage-format.json|yaml
│
├── tools/                           Organized MCP tools
│   ├── README.md
│   ├── stc/                         11 STC tools
│   ├── narrative/                   3 Narrative tools
│   ├── knowledge-graph/             9 KG tools (with fork credit)
│   └── system/                      1 System tool
│
└── examples/                        ✨ Usage examples
    └── README.md
```
